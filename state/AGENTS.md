- Never edit a completed result to fit a conclusion.
- Preserve source ref, path, SHA-256, detector version, boundary, representation, task ID, and call accounting.
- A new batch, workflow, branch, or chat never resets an existing audit/section call cap.
- `state/LESSON-INBOX.json` registers review identity here; canonical semantic dispositions live on `main`.
- Governance-only files may be added, but never mingle compliance prose with detector result JSON.
