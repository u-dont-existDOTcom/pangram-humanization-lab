Each change is shown inside its article section, with the unchanged passage immediately before and after. Yellow placement labels tell you exactly where an insertion, replacement, or removal occurs. Gray dashed boxes are context only; comments attach to the actual changed boxes.
Keep, Remove, and Brainstorm are saved per box. Clicking ＋ again reopens the existing comment. Enter saves; Shift+Enter inserts a line break; Escape cancels. The settings now sit on their own line: Humor (No jokes → Playful), Technical detail (Plain language → Expert), Length (Tightest → Expanded), and Bluntness (Gentlest → Sharpest). They do not authorize changes to claims, evidence, certainty, recommendations, attribution, causal meaning, links, or native-object placement.
