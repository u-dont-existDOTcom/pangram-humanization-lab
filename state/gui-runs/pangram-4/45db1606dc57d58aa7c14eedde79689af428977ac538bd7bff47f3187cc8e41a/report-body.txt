### Write It. Don't Send It Yet.
You're angry and the reply is already open. Write it. This is the version that stays with you for now, so it doesn't have to win a civility award.
Come back later and see what is still true. Maybe half the message was trying to hurt them back and you don't need that part. Maybe the angry sentence is also the first time you actually said no. If you owe an apology, don't hide from it. If the protest is valid, don't delete it just because the delivery was terrible. You're allowed to end up with a calmer message that is not a softer boundary.
Sometimes the whole response is, “I need some time. I'll give you a fuller response tomorrow.” If you say tomorrow, show up tomorrow. Sometimes you send less. Sometimes nothing. If someone needs protecting now, deal with that now; the draft can wait.
And don't throw the first version away emotionally just because you cleaned it up on the screen. Read it once more. What was the writer of that mess trying to get somebody to understand? Did they need protection, reassurance, help? The polished response is for the other person. The care is for the person who had to write the ugly one.
