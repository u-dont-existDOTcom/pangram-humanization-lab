# Owner goal — transfer, not owner reauthoring

Date: 2026-09-19
Status: **ACTIVE OWNER GOAL RULE**

Joel explicitly corrected the humanization program:

> i can write this myself even better than you so i don't need you for this. what i need you to learn is how to write well.

## Rule

Owner prose and rough cognition are supervision/training evidence, not a substitute for model competence.

Do not count these as learning success:
- near-verbatim cleanup of Joel's words;
- owner-written anchor masking model prose;
- asking Joel to supply every difficult paragraph;
- detector success caused primarily by owner prose.

## Genuine transfer criterion

A learned writing capability requires model-generated prose on a target whose wording Joel did not supply, while preserving source meaning and passing both:
- Joel's editorial judgment;
- valid paragraph-level detector evidence where measurable.

At least one new-target transfer is required before promoting a lesson from local recovery tactic to reusable generation competence.

## Current evidence

The program has learned several useful failure mechanisms:
- semantic-led generation can turn a ledger into prose;
- literal transformation can inherit AI discourse structure;
- over-cleaning owner thought dehumanizes it;
- Human anchors can distort detector scoring;
- paragraph-level checks prevent masking.

But these are **diagnostic/method lessons**, not yet proof that the model can autonomously write well.

Use owner cognition to teach. Then test transfer without copying it.
