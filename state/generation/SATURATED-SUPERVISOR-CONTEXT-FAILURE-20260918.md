# Provisional method finding — saturated supervisor context can preserve the semantic staircase

Date: 2026-09-18
Status: **PROVISIONAL HUMANIZATION METHOD FINDING / ONE-TARGET EVIDENCE**

## Trigger

Inner Child Therapy Candidate D was generated after explicitly restoring the validated Episode 007 Phase-A instruction: broad natural-boundary realization, no local green locks, preservation ledger used only afterward.

The prose still reproduced a compact function-by-function architecture.

## Supported finding

Changing the **instruction** from local repair to broad rewrite is not sufficient when the writer is the same context that has already absorbed:

- the preservation ledger;
- repeated sentence-job audits;
- many rejected candidate architectures;
- anti-pattern diagnoses;
- current owner calibration rules.

The model may continue to generate from those activated abstractions even when told not to use them as an outline.

This is not proof of a universal context-window effect. It is direct process evidence on the current target that the same saturated supervisor context did not faithfully realize the intended low-ledger Phase-A writer role.

## Practical consequence

When the method question is whether semantic/critic activation itself is shaping prose, same-context role separation cannot test it.

Use a genuinely fresh context.

For the next Inner Child experiment, the writer receives literal prose only:
- accepted preceding context;
- exact failed subsection;
- immutable owner paragraph;
- following boundary;
- preserve-meaning instruction.

The supervisor retains the ledger and all diagnostics for afterward.

## Difference from R17

R17 was fresh but still received a rich writing environment:
- enumerated remaining functions;
- multiple literal calibration demonstrations;
- complete successful model reference;
- cadence/efficiency guidance.

The new experiment removes both supervisor saturation **and** packet-density/semantic-outline pressure.

Its purpose is to discriminate whether lean literal transformation is materially better than rich semantic instruction.

## Failure threshold

One attempt.

If the lean isolated writer still returns the same broad model-shaped architecture, do not add another rule stack. Treat the context-pollution / packet-density hypothesis as insufficient for this target and switch architecture again.
