# Owner calibration — vague `the thing` placeholder tic

Date: 2026-09-18
Status: **ACTIVE OWNER-CALIBRATED GENERATION LESSON**

## Trigger

During Inner Child Therapy humanization review, Joel directly objected to the generated sentence:

> `But you're talking about the thing now.`

Owner instruction:

> `let's stop using "the thing" as a tic. save that durably i hate that so much`

## Production rule

In fresh Joel-byline model-generated prose, avoid vague placeholder uses of:

- `the thing`
- `that thing`
- `the whole thing`

when the phrase is merely standing in for a concrete referent the prose already knows, or when the sentence can be written more naturally without a placeholder noun.

This is an **owner-disliked model tic**, not a universal English-language ban.

Do not mechanically rewrite:
- exact owner-authored or owner-locked prose;
- quotations;
- titles;
- a genuinely idiomatic use where `thing` is the most natural and precise realization;
- source language that must remain exact.

## Repair target

When the model is about to write a vague `the thing` placeholder:

1. name the actual referent if doing so sounds natural;
2. use a pronoun or verb construction if the noun is unnecessary;
3. restructure the sentence if naming the referent would create stiff repetition;
4. do not replace it with another vague synonym such as `the issue`, `the situation`, or `the matter` merely to evade the literal phrase.

The correction is about vague placeholder habit, not token substitution.

## Current example

Rejected generated wording:

> `But you're talking about the thing now.`

The live referent is the original concern/problem the reader raised. A successor should either name that naturally or avoid the placeholder construction entirely.

## Scope

Activate this lesson for future humanization/generation intended for Joel's byline. Treat repeated vague `thing` constructions as a style-review flag. Preserve legitimate owner uses unless there is an independent editorial reason to change them.
