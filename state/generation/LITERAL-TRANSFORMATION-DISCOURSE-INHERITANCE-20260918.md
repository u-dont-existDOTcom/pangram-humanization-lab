# Provisional method finding — literal humanization can inherit model discourse architecture

Date: 2026-09-18
Status: **ACTIVE METHOD FINDING / CURRENT INNER CHILD TARGET**

## Trigger

A genuinely fresh writer was given a lean packet containing:
- accepted preceding article context;
- one exact failed model subsection;
- one immutable owner paragraph;
- the following heading boundary;
- a simple preserve-meaning / humanize instruction.

It did not receive:
- preservation ledgers;
- anti-pattern lists;
- detector expectations;
- calibration corpora;
- rejected-candidate history.

The returned prose still reproduced nearly the same discourse architecture as the failed input.

## Supported finding

Direct literal transformation can preserve a model-shaped **discourse plan** even when context saturation and prompt-rule density are removed.

The fresh output changed wording and local order but retained:

`single bad interaction -> caution -> later-engagement caveat -> repeated-pattern pivot -> source classification -> owner paragraph -> repair -> fairness qualification -> understanding failure -> guilt adjudication -> tidy unresolved close`.

Therefore a lean rewrite instruction does not necessarily break the architecture embedded in the source prose.

## Relationship to semantic-led generation

The project has now observed complementary failures:

1. **semantic/function-led input**
   - preservation/function ledger becomes latent prose outline;

2. **literal model-prose input**
   - model discourse plan is inherited and paraphrased.

Neither representation should be treated as a universal solution.

## Independent owner-tic evidence

The isolated writer independently generated:

`Then there's the thing that keeps happening...`

even though the fresh packet intentionally omitted Joel's active `the thing` correction.

This strengthens the interpretation that vague `the thing` is a model-default tic on this writing surface rather than merely an artifact of the saturated supervisor context.

## Process implication

Do not repeat lean literal rewriting indefinitely.

When both semantic-led and literal-led generation reproduce the same architecture, acquire external localization evidence before selecting another generator architecture.

Detector localization can be decision-changing even when the whole candidate is not editorially acceptable, provided:
- preservation is clean;
- the purpose is explicitly localization rather than certification;
- owner/editorial rejection still overrides detector-green spans;
- the measurement will determine whether progressive locking is available.

This matches the coarse-to-fine successful campaign more closely than an absolute rule of `never measure obviously AI prose`.
