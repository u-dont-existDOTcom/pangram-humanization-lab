R15 followed an R14 result in which the owner reported all four tested paragraphs AI and the supervising critic's strongest Human prediction (R14 P3) was falsified.

R15 was therefore planned as a materially different broad Phase-A route. The selected route was labeled `do not turn deferred judgment into self-conviction` and explicitly warned against the R14 synthetic-example mini-essay and the R13/R14 Gibson sequence.

A later pre-detector re-audit found that the route label changed more than the actual whole-boundary function topology.

## Finding 1 — route labels are not architecture evidence

A plan can name a different governing movement while still serializing essentially the same protected functions in the same order.

R15's actual whole-boundary movement remained approximately:

`self-blame correction -> repair -> one-event caveat -> recurrence -> Gibson -> motive uncertainty -> no need for more injury -> revisability -> promise vs behavior -> failed mutual understanding -> ending`

This overlaps the rejected R13/R14 counselor framework even though the opening social move was genuinely different.

**Rule:** anti-isomorphism must be performed on the literal completed output's whole-boundary functional skeleton. Do not accept a route as structurally different merely because the plan gives it a different conceptual name.

## Finding 2 — paragraph boundaries can hide framework survival

The first R15 audit compared the rejected sequence mainly inside the Gibson paragraph. Because `revisability` and `promise vs behavior` moved into the following paragraph, it concluded the old framework had been broken.

That was a false negative. The framework crossed a paragraph boundary.

**Rule:** when the prior failure is a serial conceptual architecture, reduce the complete natural boundary, not each paragraph independently, before deciding that the architecture disappeared.

## Finding 3 — preservation ledgers can become scaffolds without being copied verbatim

R15's plan explicitly said the preservation ledger was not the prose outline. Nevertheless, the selected route itself walked through most protected functions serially.

The contamination mechanism does not require literal copying of ledger bullets. A writer can internalize the ledger as an ordered completion task and produce a compact comprehensive framework.

**Rule:** in broad generation, keep the full preservation ledger for post-generation fidelity proof, but do not necessarily expose its serialized form as the writer's active composition scaffold. The generation interface should privilege live thought movement and literal transformation demonstrations.

## Finding 4 — retrieval-first means literal demonstrations in the generation interface

The active retrieval-first protocol requires 2–4 eligible literal aligned transformations selected by rhetorical job. Merely reading the corpus before planning is not equivalent.

R15's durable plan is dominated by abstract route descriptions, preservation functions, and anti-pattern checks. The writer did not receive a compact literal before→after demonstration set as the primary transfer interface.

**Rule:** if claiming retrieval-first generation, record which literal eligible episodes were actually supplied to the writer. Abstract lesson activation alone is not retrieval-first execution evidence.

## Finding 5 — preservation mapping must test object and certainty, not just topical coverage

The first R15 preservation audit accepted plausible topic-level mappings that later failed closer inspection:

- `one event does not prove emotional immaturity` became wording that could mean `there was not much grievance to say`;
- `harm requiring repair` narrowed to `mean -> apologize`;
- `ending without prolonged defense can count` strengthened into `That's the ending.`

**Rule:** source→candidate mapping is not enough when actor, object, scope, modality, or certainty changes. Preservation review must ask whether the candidate makes the same claim about the same thing at the same strength.

## Finding 6 — separate campaign strategy from writer architecture

The Episode 007 success still supports coarse-to-fine iterative convergence with progressive locking as the **campaign controller**: broad scope before green islands, then evidence-guided localization.

R14/R15 instead challenge the current **same-context Phase-A writer architecture**: saturated plan -> generate -> self-audit in a context containing repeated rejected candidates and extensive anti-pattern rationale.

These are different layers.

Therefore the correct response is not `abandon coarse-to-fine`. It is:

- retain coarse-to-fine scope/locking control;
- pause materially similar same-context Phase-A generation;
- compare a genuinely fresh/minimal-context writer architecture or another structurally independent generation lane;
- preserve source/fidelity and run whole-boundary anti-isomorphism after generation;
- return to regional/local repair only after reliable green islands exist.
