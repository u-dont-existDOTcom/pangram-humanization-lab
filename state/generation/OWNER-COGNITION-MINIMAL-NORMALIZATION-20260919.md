# Owner cognition can survive when minimally normalized; model completion can erase it

Date: 2026-09-19
Status: **ACTIVE METHOD LESSON**

## Evidence

For one paragraph, the model first reorganized Joel's rough cognition into cleaner prose. That version scored only 34.99% Human.

A second version preserved Joel's wording and sequence much more literally, with only light normalization.

That paragraph independently scored:
- Pangram 4.0
- Human 1.0
- AI 0.0.

For the companion paragraph, Joel supplied a vivid 41-word thought:
adult holding the inner child's hand and showing him a better way, rather than stealing his pencil.

The raw owner thought was too short for the current GUI threshold.

When the model expanded it with explanatory source functions, the resulting 81-word paragraph scored AI 1.0.

## Lesson

When owner rough cognition is available:
- treat its **order, emphasis, awkwardness and local wording as evidence**, not merely its semantic content;
- do not summarize it into cleaner concepts unless necessary;
- minimal normalization can preserve Human thought shape;
- model-authored completion around a short Human fragment can reconstruct the same efficient explanatory architecture and destroy that benefit.

If a short owner fragment lacks enough source coverage, ask for more owner cognition rather than filling the gap with generic counselor prose after repeated failure.

This is not a universal requirement for owner authorship; it is a recovery tactic after model-only generation has saturated.
