# Inner Child Episode 008 R13 — prediction scaffold + method-fidelity failure

Status: PROVISIONAL METHOD EVIDENCE
Date: 2026-09-17

## Trigger

After the validated Episode 007 local-repair success, a later Episode 008 R13 attempt intentionally restored the method label:

`literal current span -> explicit operation -> concrete positive target -> frozen guide -> later generation`

R13 was materially better than R12 but still reproduced the same hidden comprehensive counselor architecture. A producing-method audit found that the run had restored the method's *surface form* without reproducing the successful endpoint's sparsity or informational conditions.

## Key evidence

The R13 plan contained ten local repair jobs, many semantic preservation constraints, three complete owner-facing prose predictions, and an explicit recommendation for Prediction A. The plan was approximately 18.6 KB for a 265-word generated candidate.

The final successful Episode 007 residual repair had a much narrower environment: one 39-word AI/high residual was localized, known-Human neighboring prose was frozen, and the final repair guide was roughly 2.5 KB.

R13 then followed recommended Prediction A closely, including a near-identical final handoff idea:

- Prediction A: `If the rest of the argument is still yelling in your head, write it there first.`
- R13: `If the rest of the argument is still yelling in your head, give it somewhere private to yell first.`

The R13 output also converted known failed structures into isomorphic variants:

- diagnostic questions -> declarative relationship criteria;
- `Maybe / Maybe / both can be true` -> `you may X and still Y; guilt proves neither`;
- serial preservation units -> compressed serial preservation units.

No Pangram call was run because editorial/method re-audit rejected the candidate first.

## Findings

### Method identity includes edit sparsity

`literal span -> operation -> positive target` is not sufficient by itself to establish method identity. A plan can use that syntax for ten spans and still create a comprehensive model writing environment unlike the successful bounded residual-repair loop.

When a prior success depended on a localized residual plus frozen Human neighbors, compare edit scope/sparsity before claiming faithful method reproduction.

### Owner-facing predictions can become generation scaffolds

Three actual-prose predictions remain useful for owner calibration when the owner wants to inspect model assumptions. They are not informationally neutral once present in the writer's context.

If a later experiment is meant to test whether owner teaching transferred independently of those predictions, telling the same-context writer `do not copy the prediction` does not create isolation. Use a genuinely fresh context that contains the authorized target meaning and eligible teaching demonstrations but not the prediction prose or prior rationales.

Do not call same-context prediction exclusion `blind`, `fresh`, or independent.

### Plan-row compliance is not implementation fidelity

A writer may faithfully execute every listed operation while preserving the exact hidden architecture the plan was intended to remove.

Implementation audit therefore needs an **anti-isomorphism check** against the diagnosed failure topology. Ask whether the old conceptual outline survives under renamed syntax, not merely whether each row was followed.

### Protected function is not realization authority

R13's initial cold audit correctly identified a residual mini-framework/soft-criteria risk but passed it because those functions were protected and the paragraph was compressed. That was an admission error.

Preservation answers `must the function survive?`; cold audit answers `is this realization acceptable?`. A protected function may require a different realization. Do not use `preserve-with-reason` as a way to admit the same failed architecture.

## Current implication

Do not respond to R13 by adding another anti-pattern layer around the same whole-subsection repair template.

The next discriminating comparison should include a genuinely fresh retrieval-first writer context that excludes owner-facing prediction prose and accumulated repair rationale, while preserving exact source meaning and authority. Compare that against any alternative only after defining what evidence would distinguish the methods.
