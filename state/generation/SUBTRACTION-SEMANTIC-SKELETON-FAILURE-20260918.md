# Owner-calibrated method lesson — subtraction can expose an AI semantic skeleton

Date: 2026-09-18
Status: **ACTIVE HUMANIZATION METHOD LESSON**

## Trigger

Inner Child Therapy Candidate C was produced with a subtraction-first strategy:

1. start from model-shaped Candidate B2;
2. delete criterion-setting, source-significance bridges, fairness aftercare, slogan packaging, and permission closure;
3. freeze the no-new-prose skeleton;
4. identify preservation gaps;
5. generate only the missing functions.

This removed obvious model aftercare, but the resulting prose still read strongly model-shaped.

## Failure mechanism

The subtraction strategy optimized directly into a **semantic skeleton**.

Once explanatory packaging was removed, almost every surviving sentence carried a protected function with very little social/cognitive residue between them. Regeneration then filled only the missing ledger items.

The result was exactly the owner-identified warning:

**predictable marching advancement / sustained near-maximum semantic efficiency.**

Candidate C's model wrapper effectively became:

`bad conversation -> later return -> disagreement/boundary -> one-event caution -> repeated-pattern source -> harm/repair -> self-abandonment -> guilt adjudication -> failed understanding -> stop defending`

The prose was shorter and cleaner, but not more human.

## Lesson

Do not equate any of these with humanization:

- fewer words;
- fewer explanatory sentences;
- removal of aftercare;
- smaller preservation gap;
- direct one-sentence-per-function coverage;
- a clean subtraction-only skeleton.

Subtraction is useful when it reveals a naturally moving passage underneath. It fails when the residue is merely the preservation ledger in sentence form.

## Phase rule

Before narrowing to literal subtraction/residual repair, ask whether the current natural boundary has **evidence-supported good islands**.

If not, compare against the full successful campaign phase.

For the current Inner Child subsection, Episode 007's validated method says:

- no demonstrated model-written green islands -> remain in **broad natural-boundary Phase A**;
- broad architecture, reader relationship, thought order, and register may need re-realization;
- use the preservation ledger after generation as fidelity evidence, not as the order of generation;
- only localize/freeze after owner/detector evidence actually earns that localization.

Do not manufacture Phase B/C by structurally shrinking the task before green evidence exists.

## Relationship to minimum edit dose

Minimum edit dose remains correct **after** reliable local evidence exists.

It does not mean the smallest possible edit is always the right move. When the whole model-written boundary still shares one architecture defect, a larger re-realization can be the lower-risk operation because local edits otherwise preserve the bad architecture.

## Practical check

After subtraction, reduce the surviving sentences to their jobs.

If the list now looks even more like the preservation ledger, stop. Do not regenerate missing functions one by one.

Return to broad realization of the complete natural boundary, preserving owner-locked text exactly and using the ledger only for the later fidelity proof.
