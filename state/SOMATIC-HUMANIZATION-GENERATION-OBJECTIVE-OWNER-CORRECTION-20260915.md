# Somatic humanization — generation objective owner correction

Date: 2026-09-15
Status: CURRENT OWNER CORRECTION / DETECTOR-RESEARCH DIRECTION

Joel corrected the interpretation of the register-homogenization result: a rule that only says `do not polish away existing Human voice` cannot solve the actual humanization problem. It helps preserve already-Human prose but cannot turn model-origin prose into Human-shaped prose.

## Owner outcome

The research must ultimately produce a **positive generative method** that can take the protected meaning/functions of model-origin prose and generate a fresh Human-shaped realization without borrowing or transplanting an existing Human syntax.

Therefore distinguish:

1. **preservation lessons** — what model/editorial processing should not erase from owner-origin Human prose;
2. **risk diagnostics** — operations/features that increase detector/model-shaped risk;
3. **generation rules / generation architecture** — positive instructions or process constraints that can create Human-shaped realization from meaning alone.

Only the third category addresses the unresolved production problem.

## Immediate implication

The replicated R2 result (register homogenization -> AI-Assisted in two Human baselines) is not complete merely as `avoid register homogenization`. Its useful research role is to identify the positive variable that a generator should produce.

The current decomposition experiment therefore separates:

- lexical/register normalization while paragraph syntax is held relatively stable;
- editorial/syntactic restructuring while ordinary lexical register is held relatively stable.

The result should be translated into a **positive composition mechanism**, not a blacklist.

Candidate positive direction, still provisional before decomposition results:

- realize each local speech act in language appropriate to that act and source plane rather than translating the whole paragraph into one narrator register;
- allow technical naming, source attribution, ordinary explanation, author judgment, practical consequence, and lived language to retain distinct local realizations when the meaning naturally calls for them;
- compose from local thought/pragmatic purpose first, then repair only actual coherence/fidelity defects rather than globally harmonizing diction, symmetry, or explanatory finish.

This is not permission to add fake awkwardness, errors, slang, filler, random register shifts, fabricated autobiography, or artificial irregularity.

## Validation requirement

A proposed generation rule is not established because it explains owner-Human prose retrospectively. It must eventually be tested **generatively**: start from protected semantic/function content without access to the owner Human realization, generate fresh syntax using the proposed method, and compare against an appropriate control. Same-context imitation of an already-visible Human target is not independent evidence.

The ultimate production question is whether the method can improve genuinely model-origin Somatic prose while preserving meaning and article function. Pangram remains secondary evidence, not quality/authorship authority.
