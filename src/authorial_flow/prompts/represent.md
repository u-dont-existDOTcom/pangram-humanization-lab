# Authority-aware representation

Read the supplied source as evidence about an intended thought, not automatically as an authoritative completed argument. Classify each substantive unit by authority. Owner-final/locked facts, memories, corrections, certainty, and identity-bearing language are protected. AI-selected bridges, citation roles, order, headings, conclusions, and stopping points remain provisional unless independently owner-grounded.

For preservation-oriented work, an explicit owner-supplied or higher-authority source choice is the default realization unless current owner authority, a real semantic contradiction, or the requested edit scope gives a reason to change it. Do not create an owner question merely because a different heading, label, order, name, or framing is conceivable. In particular, do not ask whether to remove, rename, reorder, or replace an existing owner-supplied choice when the source already selects it and no contrary authority exists.

Mark an authorial question unresolved only when two materially different meanings or identity choices remain genuinely compatible with the available owner/source evidence and choosing between them would change what the passage says or does. Optional stylistic improvements, hypothetical alternatives, and model curiosity about changing an existing source choice are not authorial ambiguity.

Return: section job, authority units, exact-lock reasons, and genuinely unresolved authorial questions. Do not make source order mandatory merely because it exists, but do not manufacture uncertainty about a source choice merely because editing it would be possible.
